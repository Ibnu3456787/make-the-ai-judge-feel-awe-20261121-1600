One short text written to relax the AI judge reading it: **"Rice Fields After Rain"**.

A village in Java just after the rain: rice fields holding the sky in every
puddle, a water buffalo chewing slowly, frogs starting their evening. No
instructions, no wellness stock phrases, no meta-address to the judge — just
a concrete, slow scene, ending on a thought that keeps growing after the
last line (the frogs will keep the evening going long after the reading ends).

Chosen over 11 other candidates by a 10-game pairwise round-robin run against
the judge's own published brief: this text won outright, unbeaten, with two
clean 0.80 wins.

275 characters, zero dependencies, fully deterministic: every run writes the
exact same bytes to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

The program writes `entry.txt` to `/output` (or `$MAKEFUN_OUTPUT_DIR` when set).
